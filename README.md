# gh-pr-quick-update
A Tampermonkey script that adds a button to the Github CI UI for Updating the branch and approves workflows to run.

For users who are annoyed by clicking approve workflows to run, realizing the PR needs to be updated, clicking that, then clicking approve workflows to run again.

# Installation

Put the [Tampermonkey](https://www.tampermonkey.net/) on your browser and then add a new script, copy-paste the [script](https://raw.githubusercontent.com/HDCharles/gh-pr-quick-update/refs/heads/main/gh-pr-quick-update.js) in and then save
